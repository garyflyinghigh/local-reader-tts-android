# 本地听书

[English](README_EN.md)

本地听书是一款基于 Flutter 的 Android 本地阅读应用，支持导入 TXT 和 EPUB 文件，并使用系统 TTS 进行朗读。它面向离线个人阅读场景：从设备导入书籍、自动记录阅读位置，并可随时在阅读和听书之间切换。

## 功能

- 导入本地 `.txt` 和 `.epub` 书籍。
- 保留最近书架，方便快速继续阅读。
- 自动保存章节、滚动进度和当前朗读句子。
- TXT 支持中文章节标题识别。
- EPUB 支持章节解析，并尽量内联显示书内图片。
- 支持目录浏览和章节跳转。
- 支持调节阅读字号。
- 支持播放、暂停、上一句、下一句。
- 朗读时高亮当前句子。
- 支持设置系统 TTS 的语速、音调和音色。
- 朗读时可使用 Android 媒体通知控制。

## 使用方法

1. 在 Android 设备上安装 APK。
2. 打开应用，点击导入按钮。
3. 从本地存储选择 `.txt` 或 `.epub` 文件。
4. 在书架中点击书籍即可继续阅读。
5. 在阅读页点击目录按钮切换章节。
6. 使用底部控制栏调节字号并控制朗读。
7. 打开朗读设置可选择语速、音调或系统音色。
8. 长按书籍，或使用书籍菜单，可从书架移除记录；该操作不会删除原始文件。

## 注意事项

- 本应用只读取本地文件，不包含在线书城或下载功能。
- 朗读质量和可选音色取决于设备安装的系统 TTS 引擎。
- 如果书籍原文件被移动或删除，请从新位置重新导入。
- EPUB 显示以可读文本和常见内联图片为主，复杂排版可能与专业 EPUB 阅读器不完全一致。

## 从源码构建

安装 Flutter 后运行：

```bash
flutter pub get
flutter build apk --release
```

发布 APK 会生成在：

```text
build/app/outputs/flutter-apk/app-release.apk
```

## 隐私

书籍文件保留在你的设备上。应用只会通过平台本地偏好设置保存书架信息和阅读进度。
